# PRD — Skin System 2.0 (Phase 1)

## Problem

Skins are yolk accessories. Players cannot feel a new character, only a hat.

## Goal

Skin = visual character. Gameplay stays one controller.

## Phase 1

- SkinDefinition + registry + visualId
- Wardrobe with owned / locked 3D preview and 360 drag
- Default Yolk + Knight + Bear full characters
- Equip owned; preview unowned
- Same visuals in gameplay and home canvas

## Out of scope

Rabbit, Robot, GLB pipeline, licensed collabs, create-skin automation, banners.
