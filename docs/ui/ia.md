# Yolk Rush information architecture (V6)

Flow: HOME → PLAY (level select) → countdown → race → RESULT → Next / Again / Home.

Hub tabs: home, play, character, inventory, profile. Settings is the gear, not a tab.

Data: `useGameStore` persists character, inventory, levels, settings, xp, gamesPlayed. Stats are real; empty shows 0 / --.

P0: hub nav, result trophy/confetti, next/replay/home. P1: dedicated 3D preview camera, more cosmetics.
